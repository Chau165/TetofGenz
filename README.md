
# Tet of Gen Z

### 3D Adventure Game | Unity 6 | C#

Tet of Gen Z is a 3D adventure game inspired by Vietnamese Tet (Lunar New Year) traditions and culture.

The game features interactive environments, character exploration, NPC dialogue, and quest-based gameplay across different locations.

This project was developed as a university team project using Unity and C#.

## Key Features

- 3D character movement and camera controls

- Quest progression and gameplay state management
- Interactive environments and multiple game scenes
- Character animations and 3D asset integration

## Project Structure

- `Assets/Scripts/` - Gameplay logic and systems
- `Assets/Scenes/` - Game scenes and levels
- `Assets/Art/` - 3D models and environmental assets
- `Packages/` - Unity package dependencies
- `ProjectSettings/` - Unity project settings

## Getting Started

1. Clone the repository:

   git clone https://github.com/Chau165/TetofGenz.git

2. Open the project in Unity Hub.
3. Use Unity Editor 6000.4.7f1.
4. Open a game scene from `Assets/Scenes/`.
5. Press Play in Unity Editor.

Note: The project may require importing third-party assets and resolving package dependencies.
